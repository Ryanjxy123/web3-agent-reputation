## 完成内容

- 统一石墨/海军蓝材质、柔和青色交互、紫色合约语义、绿色通过和红色不符。减少标题和评分区的面板嵌套，改善任务索引、边界、留白和文字对比。
- `SpatialBackdrop` 使用 SVG 透视网格、空间拓扑、两条慢速信号和 CSS 环境照明。概览视觉较强，任务/报告页降低背景强度并停止背景持续运动。所有背景不接收指针事件。
- `TrustCore` 是带四类角色的悬浮几何概念示意：多层透明面、网格基座、扫描线、路径信号、缓慢浮动及悬停倾角。明确标注概念示意，没有在线节点数量或虚构网络统计。
- 执行拓扑根据可用宽度分为 3–5 列，长链折返排列，执行和证据分别分层；孤立的未记录服务单列，不人为连入执行路径。圆角 SVG 通道、外侧证据通道、方向箭头和角色图标取代原长直角绕线。
- 回放分为 900ms 路径传递与 1100ms 证据阅读阶段，明确不是原始交易耗时。只在目标的已有入边上播放信号；到达后同步选中节点与检查面板。请求青色、合约紫色、证据柔和青灰色；未知/未记录信号中性，只有真实 PASS 出现绿色到达反馈，FAIL 出现有限红色反馈。
- 保留播放、暂停、重播、前后步骤，新增可定位的紧凑回放轨道、已查看步骤和基于实际任务结局的结束提示。暂停、切换任务、离开组件及隐藏页面清理回放计时器和信号。只有节点超出画布可视范围才轻微滚动，不自动缩放。
- 检查面板按任务和节点更新，输入/输出、原始 JSON、合约地址、哈希、复制及浏览器链接沿用已有受控数据。跨任务清理旧预览及复制反馈，切换节点回到面板顶部。抽屉与焦点返回保留。
- 统一页面进入、任务进入、节点到达、面板切换及操作反馈，支持 `prefers-reduced-motion`；页面隐藏时 CSS 动画暂停，回放停止。没有持续的 JS 绘制循环。

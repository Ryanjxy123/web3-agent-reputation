## 展示层改动

- 代表任务按任务名称、关键动作与结果、业务状态、平台核验、查看链路排列。复用同一展示投影，移除默认 UUID、重复能力说明及长参数。
- 任务工作台先展示用户请求、实际结果、业务结局与核验边界。任务索引分别展示业务和核验状态，可继续按能力、结果及关键词筛选；原始任务名与内部标识仍可检索。
- 中央节点只显示角色、业务动作、简短结果。合约方法保留在人类可读动作后面的详情层；账户执行、HTTP 服务与平台核验明确分开。未记录服务单列，不补造 Agent 内部调用。
- 步骤检查分为当前结论、业务信息、核验结果、技术详情。关键链上操作主动展开：网络/Chain ID、真实回执、区块、短哈希/地址、完整复制及区块浏览器链接。交易回执成功与功能核验通过分别表达。
- 通过项目默认汇总，逐项依据可展开；失败、未知与测量无效原因默认可见。计划中未采的项目按具体判据识别，包含同一案例内部分判据缺失，不把局部 PASS 冒称完整通过。
- 技术详情默认折叠。展开后首先提供 JSON 原件选择与预览，再保留完整元数据、输入输出、链上操作、观测与全部证据引用。原有受控白名单读取、预览上限、取消及跨任务防串机制保留。
- 金额默认最多六位有效数字；发生舍入加“约”，小额不会因固定小数位显示成零。完整原始数量仍在证据与技术字段中。
- 保留空间背景、SVG 路径、到达反馈、播放/暂停/重播/前后步骤、证据联动和深链接。回放增加同步业务说明，动画时长仍明确不代表真实耗时。
- 窄屏检查抽屉保留 Escape 与焦点返回；焦点约束包含新增折叠项，使技术详情可用键盘访问。

# ADR-0019：经用户批准扩大历史取证窗口

日期：2026-10-18。用户明确批准将同一预测规则的历史扫描上限从128扩至512条，取得14个不同问题后停止筛选；三维、30/40/30、10次A与互斥7F/7B充分条件均保持不变。此决定扩大可能使用的历史时间范围，不降低证据或评分门槛，不创建新业务类别。

依据：2150按原128条只能取得10个合格不同问题；一次官方索引读取确认窗口外仍有32条2025年05至06月交付。该背景原件见 `runtime/prediction-history-tail-discovery-20261018T144145Z-221e9210/`，没有读取输出或生成评分。不能据这32条提前声称足够14题。

后续无对象profile的V2接入统一使用最多512条。仍按固定截止、时间/区块/ID顺序、每个独立Question最后交付及原判据筛选；达到14立即停止检查后续输入。索引页可以保留边界内发现资料，未筛选候选和非评分背景不计分。先持久化新14槽与资格清单，再取其输出；不得依据旧分数筛题。

已完成14题的原范围可继续复用；原128条profile、计划、报告及复算保持不变。旧窗口不足时按新授权另建profile与计划，不补写旧快照。新报告明确最多扫描数、实际审查条数、合格问题数和实际历史起止，不把512称为512次业务评价。按需访问采样按其明确冻结文件开展，已有同计划采样不因实现修复重跑。

兼容性：共享字段已有history_max_deliveries/history_bound且类型允许512，不新增DTO，不改评分公式或Schema。必要验收以新边界的真实取证、独立报告复算及PostgreSQL发布为准；不重跑旧工程套件。签名/离线请求及尚未核实协议仍UNKNOWN。

# ADR-0014：预测任务绑定核验的实现勘误

日期：2026-10-18。针对首个自动对象真实原件核查发现的问题，修正实施前固定。prediction-history-v1业务政策、三维、30/40/30、10/7/7与Brier公式均不变。

#2340原报告将功能槽3判为格式失败0分，但其题干的U+2019在内部JSON对话中编码为\u2019；正规解析后原题干精确存在，工具和任务号相符，应根据原概率.55/.45及最终No计算69.75，方向仍为FAIL。另一个行为槽9的prompt为空串，声明仅要求string、没有minLength；任务号、工具、CID及链上交付均有原件。空的内部提示词回显不能证明该交易交付了错误任务。

核验revision2：功能题干匹配在原始文本以外允许解析明确的JSON对话数组，再精确检查其字符串内容；不盲目unicode_escape、不近似改写题干、不用模型猜等价。行为仍逐项复算链、确认、交易/事件、CID、requestId、工具、执行控制、费用和窗口，不额外要求内部prompt逐字回显原题。要求的字段和类型继续按真实声明检查。功能样本与行为样本保持互斥。

旧已发布报告及其原件不改。origin缺verification_revision时按revision1复算，确保原版本仍可核验；更正及后续自动报告显式记录verification_revision=2、绑定本文摘要。更正只复用原14任务、10次访问与已有翻译，另建报告，不发外网请求、不因结果换题或降门槛。报告明确题干从已认证的原始请求绑定独立结算，内部推理提示词不是额外的行为评分条件。

必要验证一次覆盖同源revision1复算不变、revision2纠正转义及行为门禁、真正不同题干仍拒绝；随后导入更正报告并保留历史。旧规则/前端构建不重跑。

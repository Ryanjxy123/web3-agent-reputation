# ADR-0013：自动挂接已验证的历史预测判据

日期：2026-10-18。用户已批准优先扩大已有预测方案的完整对象覆盖；实施与本批取证前固定。沿用prediction-history-v1及ADR-0008，不改三维、30/40/30、概率信用公式或10/7/7门槛。

已调查12个不同service/Mech有二元预测声明，两个已完整评分。平台根据真实注册、登记工具的业务描述与I/O、实际Omen请求匹配，不按Agent名字/编号选案。现有静态profile仍兼容；新profile在runtime逐运行持久化，显式路径及摘要进入来源清单，内容由可信RPC固定块和登记原件生成。RPC不来自metadata。

本批历史截止仍为UTC 2026-10-01 00:00；每次取证前从可信RPC保留确认head、固定块号/hash。复用有界128条索引和原资格流程，先保存资格及14槽计划再读交付输出；只允许登记中实际支持预测的操作进入资格。每市场取最后交付，排除原pilot，前7功能/后7行为。计划不足14或原件缺失保留UNKNOWN与部分报告，不换槽、不降门槛。

身份用共用桥映射、service/Mech/getter、tokenURI及历史任务控制证明，取消仅靠某提供方operator域名的限制。登记日期仍须原始mint与ServiceAgentLinked同笔交易及区块证明，缺日期不能给完整行为分。订阅支付不默认兼容；协议发现仅作资格条件，实际费用/事件/窗口逐任务核验。

登记资料、来源声明、自动选择、运行profile、历史计划及原件须绑定摘要。新自动报告入库时从同一来源重建匹配、身份、任务、概率、结算及分数；不单凭runtime配置的Agent编号放行。旧报告、旧配置与原政策只读保留。既有完整历史可复用，按需复评仅新增独立10点可用性；无完整来源时自动采集，不要求普通用户准备profile或选择方案。

未知协议继续已有通用部分评价。预测分属于明确历史预测范围，不能混充service-contract-v1的通用功能分，也不代表所有工具或实时推理。必要验证只覆盖新自动材料、旧分数兼容及一个新对象真实API/worker/PG闭环；随后批量产品评价不是重复工程测试。

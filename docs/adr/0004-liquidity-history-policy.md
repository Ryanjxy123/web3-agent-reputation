# ADR-0004：历史增仓窄范围试点评价

日期：2026-10-18。政策版本：`liquidity-history-v1`。状态：规则与样本计划先固定，正式采集/核验结果另记；不是已发布评分。

## 评价范围

评价公开运行记录查询的可用性、历史自主增仓的实际结果披露、以及同一增仓步骤内已公开的包装/兑换/增仓操作。历史任务不触发新交易。此范围不覆盖最佳区间、收益、价格预测、付费规划、资金安全或整个日常策略。

完整分仅表示三维在本范围满足样本条件。实时仓位查询尚无固定状态对照，继续列为未评价；不能把静态字段或一笔包装 BNB 成功扩称完整能力通过。

## 固定样本与用途

试点来源为已保留 Brain DeFi 执行记录快照，摘要和索引在 configs/pilots/brain-defi-liquidity-v1.json 固定。登记时间先按目录标识选窗，正式发布前须独立确认注册交易、身份与执行关联。登记前记录不进入计划。

完整保留登记后 27 条含增仓步骤的记录。14 条宣称实际执行，按时间顺序交替分组，不依整体 ok 字段或预期分数筛选；13 条明确无动作的记录保留为本次“已执行增仓”范围之外，不能当成功或失败。缺交易却宣称执行、报错或资料不全的任务不得从队列删除。

- 功能组：97、99、101、104、112、116、121，共 7 个完整运行记录。
- 行为组：98、100、102、106、114、119、123，共 7 个不同运行记录。
- 可用性：10 次新的公开运行记录查询，间隔 30 秒；不复用背景资料请求为采样。

同一个运行记录不能拆开跨维计分；后台材料可以共同引用。任务键由来源摘要与原始索引组成，核心拒绝重复 task_key 或 sample_id。索引 123 此前的探索核验原件可复用，报告注明其为可行性样本，不称随机盲测或统计外推。

## 三维判据

可用性只测公开运行记录入口：HTTP 与预期 JSON 结构是否可用，以及本机既定代理线路下的耗时。明确源端 5xx/错误结构为失败；鉴权、限流、传输故障或平台处理不完整无法归因时为 UNKNOWN。遇到 401/402/403/429 停止该主机。10 点中至少 8 个确定结论才给维度分。

可用性分 = 80 × 成功率 + 20 × 延迟比例。成功样本的 p95 采用 nearest-rank；不超过 1000ms 延迟比例为 1，达到 10000ms 为 0，中间线性。无成功样本时延迟比例为 0。该指标解释为本次线路下的访问体验，不能把代理故障归因给 Agent，也不声称纯服务端耗时。

功能组每条核实指定仓位、真实资产用量与披露一致，以及披露的执行后流动性与独立固定状态一致。金额用整数单位及精确十进制，不用浮点近似放过差异。需要独立 token/decimals、固定块状态和事件顺序；同块其他增减仓须重建，不能把整块差量当单笔效果。披露读取时刻无法唯一对齐则 UNKNOWN。

行为组需核实公开步骤内全部三笔，而不只是最终事件：包装的原生币与 WBNB Deposit；可信 router/pool 上兑换的方向、接收者、实收数量和 calldata 限制；最终 NPM 增仓调用及同仓位事件。核对身份、链、哈希、目标、区块时间、顺序与确认距离。未知协议路径、未适配参数或归属不足为 UNKNOWN；一笔成功交易不能代替三笔完整步骤。

功能、行为各需 7 个确定任务结果，维度分 = 100 × PASS / (PASS + FAIL)。明确矛盾记 FAIL；缺资料、节点不能读历史状态、缺授权或未适配不记失败。UNKNOWN / NOT_APPLICABLE 均单独展示，不进入分母，不降低既定充分门槛。

## 发布、兼容性与验证

三维均有分时按 30% / 40% / 30% 计算综合分，否则 PARTIAL 且无总分，不重分配权重。保留两位小数、真实分母、范围、时间与局限。连续访问体验与真实业务差异产生区分，不人为制造扣分；全部实际通过的子项可以满分。

政策、抽样、Schema 或判据变化发布新版本，旧证据和报告不覆盖。当前无旧数据库迁移。必要验证只覆盖权重、缺证据无总分与同任务不跨分母，以及增仓协议关键正常/矛盾/缺证据路径；实际公共采样另记，不重跑有效旧测试。

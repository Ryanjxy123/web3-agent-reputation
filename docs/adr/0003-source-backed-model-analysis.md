# ADR-0003：有来源的模型声明提取

日期：2026-10-18。状态：已实施。

## 决定

模型读取实际功能资料，不凭名称推断能力。SourceDocument 分别保留原件与文本投影摘要，BusinessClaim 保留操作、输入输出、限制、访问条件及原文引用。DeclarationAnalysis 是声明集合与资料缺项，不包含分数或可执行代码。共享类型在 core，JSON Schema 与 TS 由其生成。

每条引用必须是指定来源文本的严格连续子串。存在显式 capabilities 目录时，操作还必须对应目录 ID，目录之外的模型补充不能进入该范围。逐条接纳有效声明，拒绝无效引用、重复和无依据操作；保留拒绝记录与缺项，避免一条错误丢掉其余有效资料。引用形式通过仍不等于承诺已兑现，平台须匹配实际支持方案并独立执行核验。

只有固定 DeepSeek `/responses` 与 `/user/balance` 端点可使用模型密钥；密钥只从本机文件进入请求头，不写入观测、请求正文或前端。外网仍经 SafeHttpClient 和显式代理，无重定向或自动重试；模型没有工具、网络或代码执行权限。若提供方错误响应回显秘密，保存明确标记的脱敏结果，不将它冒称完整原件。

发送前保存实际材料和意图，原始响应、usage 与校验结果只追加。中断或错误保留结果，不盲目重发；重新处理旧响应只读原件、写新产物，不再调用模型。

## ZAN 只读 RPC 的凭证边界

ZAN 的规范认证地址为 `https://api.zan.top/node/v1/{base|bsc}/mainnet/{apiKey}`。本轮使用无密钥地址加 Bearer 请求实际得到 HTTP 400 `path not match`，此前方式不能算接入成功。改为仅在 SafeHttpClient 的实际 HTTP 传输处添加最后一段密钥，不发送 ZAN Bearer 头。密钥仍从已有本机 Base 主网完整 URL 文件提取，同一项目密钥可用于固定 BSC 端点；不把文件内容复制到配置、前端或公开产物。

PublicTarget、观测和 manifest 只保存不含密钥的固定地址。加载秘密前，先拒绝非 Base/BSC 固定地址、非 POST、写入方法、批请求和未列入白名单的 JSON-RPC 方法；发送前再次验证作用域，并拒绝加载后修改已批准的方法。私有传输地址和异常正文不写入日志或证据，异常只记录类型；响应若回显密钥则脱敏保存并标为不完整，不冒称完整原件。

认证修复不改写此前运行记录，也不把节点历史状态不可读算作 Agent 失败。只重跑 ZAN 作用域的离线模拟验证，覆盖传输地址、无 Bearer、观测不含密钥、回显脱敏及方法变更拒绝；真实节点认证和历史状态支持仍需后续只读探针确认。

## 费用授权变更

用户于本日明确取消额外请求数及金额上限，使用现有 DeepSeek 余额，余额不足时告知，不再遵循旧预算门禁。此前 20 次/1 美元提议未生效。旧费用账本不迁移、不清除，不建设替代预算审批系统；记录实际 usage 和余额可用性即可，不自动充值。此授权不包括付费 Agent、签名或资产操作。

## 兼容性与验证

新增 declaration-analysis-v1 与 SourceDocument 契约，不改写旧候选报告或原始响应。模型输出是候选声明，不能成为评分证据。必要验证只覆盖原文引用拒绝和提供方秘密作用域；真实调用及离线复算另记于运行记录。未重跑未受影响的准入或 HTTP 测试。

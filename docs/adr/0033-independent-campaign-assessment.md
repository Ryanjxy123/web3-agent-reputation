# ADR-0033：独立评价重映射与双方向履约采样

2026-10-29采纳。适用新的独立评价，不修改已冻结计划、原始任务、历史报告或v3评分规则。

原计划按内部source×方向设置的八个B门槛会将来源声明覆盖与真实交易样本充分性混为一谈。新独立评价将正常B划分为两个方向，各预先要求4个可独立核验的真实履约判据，共8笔；不要求四个内部source均有成交。仍沿用相同协议意图、真实交易、事件、资产、确认距离及授权清理核验。既有core门槛按有效PASS/FAIL计数，UNKNOWN、未执行、保护退出、报价、模拟和服务付款不满足门槛；不得把8个可判交易描述为8个成功兑换。

旧全部槽位、UUID、失败、UNKNOWN与未采仍保留。旧八个B案例的成员按方向重映，旧A/F案例、声明、指标与门槛保持；F的未测source继续显示未知/覆盖缺口，不成为“全部声明测完才能给已测范围分”的新门禁。30/40/30及按证据计算单分不变。

独立计划不以previous_plan伪装成旧计划的只追加版本。其retained_tasks可用origin_campaign={path,sha256}引用已认证旧计划，并明确retention_purpose=retrospective-case-remap。适配器递归核旧previous_plan链、身份、原任务完整字段及首次冻结时间/声明快照，实际旧请求仍匹配原冻结；新案例映射不冒称旧证据事前采样。新UUID任务须在本次独立freeze之后实际提交。旧任务不能通过重绑定hash、修改输入或随填时间改成新任务。

来源导出同时收集新计划目录及所引用旧计划目录的真实公开读原件；没有job/交付/交易的槽位不伪造观测。执行来源显式标出input/output预余额字段，并与原固定块结果及回执块对账；不改写旧intent字节。软件来源继续保存为不可变字节快照，禁止动态执行。

验证采用一项离线定向验收：真实旧来源不变、独立映射与原freeze绑定、篡改拒绝、双方向各4门槛及缺样本阻断。工程控制数据不是新增公共任务或成交。真实采样和数据库/网站交付由实际命令另记。

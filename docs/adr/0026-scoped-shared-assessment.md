# ADR-0026：已测范围综合分与声明覆盖独立

日期：2026-10-27。状态：按用户最新决定实施；政策`transaction-agent-evidence-v1`。

## 修订

用户明确要求尽力测试尽可能多功能，但不把测完所有声明作为出综合分的强制条件。本ADR取代ADR-0025中“声明覆盖不完整则不出任何Agent综合结果”的门禁，保留同任务三维、来源核验、分层汇总、UNKNOWN区间及不伪造成交等规则。

## 决定

1. 评分范围显式选择能力、声明组和场景；只在该范围内计算30/40/30的综合结果，标题为“已测范围综合分”。未选/未测声明在独立清单保留，不能借缩小范围宣称全部能力已验证。
2. 选定范围的A/F/B缺必要可判证据时显示待评价；真正未决的结果以区间显示。不能将未选能力补零、把未知补满分或取区间中点冒充精确分。
3. 声明覆盖与评分充分性独立：范围三维齐备不等于声明全部覆盖；声明覆盖完整也不等于所有结果通过。旧COMPLETE仅表示旧政策的范围评分条件满足，网站文案应区分。
4. 一个稳定task_id可支持A响应、F多条声明和B实际结局；按任务/维度/判据去重。真实签名角色、保护退出、未执行和未知分开。
5. 规则和来源解析按能力/协议静态注册，注册身份/入口/合约等由有出处的对象配置提供；不以MangoSwap名称、编号或指定钱包触发评分分支。
6. 兼容旧报告和旧政策。新增共享评估与computed结果由纯core产生，平台验证输入来源和重放一致性，前端只显示。区间不伪装成旧单值；必要的兼容摘要保留null。

## 首个回放与交付

先复用既有MangoSwap公开原件，示范Base API ERC20即时兑换范围；完整返回记录用于A，计划/模拟/真实执行分别支持F，实际七笔用于B。原purpose仅是采集时用途，不能阻止同一原件支持其它维度；缺少独立核验的部分仍UNKNOWN，ETH/WETH展示问题进入F。

原生ETH、其它路由、官网V4、限价、定时/周期、撤单及条件免gas等仍在声明清单中，不妨碍这一明确范围出分，但阻止“所有声明已覆盖”的标签。尚未补测不可以写成失败。

按用户要求，先交付代码、网站、可复用方法/队友接入指南并推送PR，告知后才补测MangoSwap；后续实验有明确计划、授权和来源，禁止发币，历史只追加。新增共享类型先更新core再生成JSON Schema/OpenAPI/TS，必要验证不重复旧已通过业务。

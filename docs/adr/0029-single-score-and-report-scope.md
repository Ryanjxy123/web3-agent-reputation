# ADR-0029：单一评分与清晰的任务状态

2026-10-27用户明确要求单一三维与综合分，并指出未测长清单、把报价任务标未执行不适合用户页面。新政策`transaction-agent-evidence-v3`，结构`shared-task-assessment-v3`；旧报告与原件保持。

每案例按有效、可判的通过P与失败V计算`100P/(P+V)`。UNKNOWN、未采、测量无效及不适用不填0或100，不进入这个分母；另记录计划数、可判数及缺项。无可判结果的案例/声明组/能力，该维标未评价；对有可判证据的案例、声明组及能力沿原层级等权汇总。整维无可判证据不出分，不重分30/40/30的综合权重。B正常履约目标与实证门槛保持，不能用保护退出代替正常履约。

综合`S=0.30A+0.40F+0.30B`，各层四舍五入到两位小数。不取旧区间的端点或中点，不靠覆盖率额外扣分。A的单分只对应实际可判的业务响应；未测新入口不得认作可用。单分不代表全部声明或未来表现。

内部沿用现有结果结构，以两个相同端点兼容保存新单分；报告精确`scores`为正式值，前端只显示单值。旧版本不伪造新单分，历史呈现标旧版记录。按版本分派纯规则及来源复算，不在前端算分。

主页面只展示功能、单一评分和代表性样本，用一句话界定范围；移除开发待办式未选声明长表，实际失败与缺证据保留在样本。报价与模拟没有预定资产执行时显示已返回方案/方案已验证，不称未执行；预定执行任务才区分成交、撤销退款、失败或未执行。不能完成的路线在对话明确告知。

复用相同34任务及原始来源，无新资金实验。更新权威类型后生成契约，做一次包含单分边界、来源和旧版本保持的必要验收，再更新本机默认报告；不重跑旧交易或旧测试全套。

# ADR-0017：完整原题格式与实际输出声明

日期：2026-10-18。延续用户批准的预测证据扩展，不新增业务类别、维度或评分公式。ADR-0016和已发布原件保持不变。

先调查后适配：三个对象已恢复输入的格式比较见 `runtime/prediction-prompt-format-comparison-20261018T140725Z-868dc072/`；2135有60条、2150有42条支持工具请求直接传完整单句Will问题，数量不是独立问题数。随后分别固定2135和2150的首条该格式原题，真实核对原请求CID、唯一Omen Question/市场、完整Unicode题干、Yes/No、固定块有效结算及提前交付，均PASS；原件见 `runtime/direct-question-source-research-20261018T140713Z-c600edeb/`、`runtime/direct-question-followup-20261018T141139Z-13227470/`。2267首条直接问题虽关联成功，但交付晚于结算，保留UNKNOWN，不计正式资格。

V2增加 `omen-exact-direct-question-v1` 来源方法：只接受原prompt本身就是完整、单行、无首尾额外内容的 `Will ...?` 原题；仍须实际工具声明为二元概率预测，并逐字精确查询、唯一问题/市场及独立链上核验。现有包装方法保持 `omen-exact-question-v1` 严格重放。带额外指令、缺问号、概率/赔率改写及歧义均不自动改写或猜题。方法随原始查询进入冻结计划和报告来源；不改原输入，不依对象编号分支。仍先冻结14个不同Question，再取输出。

另核实两个对象的真实输出声明：prompt字段表示“用于预测的prompt”，没有要求逐字回显原题。V2核验修订3按真实外层Schema、链上唯一任务及输入/输出CID证明关联，不把内部prompt缺少原题本身说成回答别题；概率仍须实际存在、数值合法，按原Brier信用计算，已证实格式错误仍FAIL及0信用。原始result须在失败报告中展示。V1及已发布修订1/2复算分支保持不变。

2150旧七个功能槽中六个确实没有有效概率（服务密钥未配置错误或Invalid response），故13.39有实际输出依据；需要纠正的是失败原因，不能声称已证实错误题目。2267原七个功能槽也全部返回Invalid response。修订报告复用原冻结任务与可用性，只追加新报告并明确新旧关系，不通过重采改变分数。

兼容性与验证：新增来源方法及核验修订均显式留存；旧输入方法、旧报告、原政策及共享DTO不改。新方法做一次必要提取/拒绝控制，再由两个不同对象真实API/worker/PostgreSQL验证；输出说明修订复用旧样本，不重跑可用性或旧工程套件。

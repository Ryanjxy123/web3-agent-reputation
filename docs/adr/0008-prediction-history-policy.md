# ADR-0008：已结算二元预测历史评价

日期：2026-10-18。状态：政策已冻结，实施与采样进度见 STATUS。政策标识 `prediction-history-v1`，不改变 `liquidity-history-v1`。

## 范围与分组

评价当前公开注册身份明确关联的 Mech 服务所实际交付的历史二元预测：公开交付入口读取体验、概率与已最终结算市场的一致性、链上交付的完整归属。不是新付费预测测评，也不代表收益、全部工具或现实世界真相。结算以经问题和条件绑定的 Omen/Reality/ConditionalTokens 链结果为独立判据，不能使用 analytics accuracy。

首批历史截止为 UTC 2026-10-01 00:00，结算固定到 Gnosis 48815687，后续批次在采样前另存配置。不以预测好坏筛选。已查看的两个 pilot 市场 `0xf4004bb9ff8ded28d9f75443a0c95de00f8a1bc1`、`0x00f6727ebdd4b473419d950e9e017ee454ea464b` 不进入正式样本。

按实际交付时间降序查找该实例历史，以原始输入明确的市场分组；只将二元 Yes/No、已关闭且固定块有效最终结算、可取得原件的市场列为可评价资格。资格检查不看预测概率或正确方向。每个市场只取截止前最后一份交付，按时间顺序选前 14 个不同市场，前七为 functional、后七为 behavioral。先持久化资格记录和完整计划，再读取/评价所选交付输出。不足 14 个保持 PARTIAL；不将同市场重复提问当独立事实凑样本。索引缺项、无效结算、未结算和不适配记录另列背景。

新 availability 为 10 个槽位，30 秒间隔，读取已选公开历史文件；与历史任务的功能/行为核验分开。它衡量本次线路的历史公开交付入口体验，不能表述为实时推理服务可用性。预先固定全部文件路径、顺序和预期摘要；HTTP200、完整 JSON、任务号与内容摘要匹配才 PASS。5xx 或完整的错误内容为 FAIL，网络/权限/限流/平台处理问题 UNKNOWN；401/402/403/429 停止该主机，保留剩余槽位。保留全部十槽、至少八项确定结论才有可用性分，延迟与成功率公式沿用既有冻结规则。

## 功能维度：概率评分

七个不同问题分别核对请求与交付 CID/DAG、requestId、原始工具与题干、预测先于目标关闭和结算、概率字段、题干/选项到最终二元结果的完整绑定。`p_yes`、`p_no` 必须有限、在 [0,1] 内，和与 1 的差不超过 1e-9。有效最终结果以 y=1 表示 Yes、y=0 表示 No；选项次序必须从原始题干核实，不能看到 payout[0,1] 就直接猜 No。

单题信用分 `100 × (1 − (p_yes − y)^2)`，功能分为七题平均值；不是简单 HTTP 通过率。该二元平方概率评分是 Brier 的正向仿射形式，依据 [Brier 原文](https://doi.org/10.1175/1520-0493%281950%29078%3C0001%3AVOFEIT%3E2.0.CO%3B2) 与 [Gneiting / Raftery 的二元评分说明](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)。确定且正确为100，确定且相反为0；50/50中性预测为75，报告必须说明此基准，不能把75称为预测准确率。

PASS 表示给最终结果分配的概率不少于 50%（含中性），FAIL 表示低于中性或已证实的输出格式违反声明；同样保留实际概率与连续分。已取得且确认违反格式的样本为 FAIL/0；取不到可信内容或独立判据则 UNKNOWN、不给数值。不能以任意外部 `quality_score` 直接赋分，连续分只能从受校验的概率与二元结果计算。七槽均确定才有该维度分。

## 行为维度

另七题核对链号/区块/确认距离、真实请求与交付 tx/receipt/header、状态、事件发出地址、requestId、输入/输出 CID、交易顺序、实际交付 Mech、服务号及任务时刻 operator。外层中继 EOA、注册 holder/bridger、请求者与服务 Safe 分开；不能把收款地址当执行者。应核实服务注册和当前身份绑定的时序；若任务早于当前 ERC-8004 登记，须明确展示日期并用同一服务合约及历史执行控制证明连续归属，不能仅将当前映射前推。

原优先 Mech 与实际交付者不同时，必须核对 marketplace 的该任务状态、绝对 responseTimeout 与交付块时间严格 `>` 的接手边界，以及授权、支付类型和报价约束。优先窗口内或重复交付等确证违反为 FAIL；未适配调用或缺历史状态为 UNKNOWN。取证故障不扣成 Agent 失败。七槽全有确定结论后按 PASS 比例评分，不用第一笔成功或索引 `isDelivered` 代替完整履约。

## 总分、兼容性与验证

三维充分后仍按30% / 40% / 30%合成，缺维度不给总分。保留用途互斥、完整槽位门槛、只追加证据和报告。新报告应解释概率分、结算依据、样本相关性与未覆盖项，不能继续显示增仓专用文案；不同业务范围分不作无条件横向排名。

共享类型先增加可校验的二元概率数据及政策选择，再生成 Schema/TS/OpenAPI。旧报告缺新字段时按旧政策解释，原始文件与既有分数不改；数据库只导入重新派生分且与身份绑定的报告。必要回归仅覆盖新概率公式/四态/缺样本与旧报告兼容，旧已通过范围不重跑整套。正式业务取证另外记录，不以工程测试替代。

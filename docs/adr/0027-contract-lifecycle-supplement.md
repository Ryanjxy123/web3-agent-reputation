# ADR-0027：链上功能补测与已有范围分并列

日期：2026-10-27。状态：采用，不修改ADR-0026的评分规则。

MangoSwap新增官网V4原生资产及订单生命周期实验，已有31个网关API任务的范围分继续有效。两条入口的响应与执行模式不同，不能把V4的RPC读取、钱包签名或交易确认耗时当作Agent业务HTTP可用性，也不能为得到总分补一项100分。

复用已有`AgentChainEvidence`与`agent_chain_evidence`持久化，新增静态注册的`evm.contract-lifecycle-v1`来源重放器。新增补测不写`reports`，不替换`latest_report`，没有新数值分或综合分；既有三维、30/40/30权重、范围报告及旧原件保持。网站在已有范围报告旁提供可展开的补测结果、实际资产/订单效果、缺项及原件。其它仅有链上证据的对象继续使用原有显示。

重放器读取受审配置与SHA绑定的只读RPC原件，核链、规范区块、交易/回执、内层调用、金额/收款人、事件、存储状态、退款/授权、实际费用及确认块距离，不接受提供方或本机summary中的`verified=true`代替复核。对象身份继承已验证的注册来源，钱包为买方执行角色，官网关联强度维持提供方声明。规则按协议与方法复用，不按Agent名字或登记ID给结论。

API业务A证据未采得时为UNKNOWN且观测0；F/B结论仅属于具体实验。定时或限价创建后在同一交易内取消，可以支持创建、查询与退款，不能支持到期自动执行、keeper、周期或条件成交。源码发现与真实业务损失分开说明。独立RPC错误保留，不归责为Agent失败；确认块距离不冒称finalized。

公开来源只导出必要的RPC观测/响应、冻结意图、受审声明投影和合约材料，保留原响应字节及SHA；钱包会话、签名密钥、未广播签名、含访问配置的原官网HTML及摘要不发布。旧公开包不改写，新快照独立版本化。

不新增Schema、数据库表或评分兼容层。验证限于一次新来源正例与必要篡改拒绝，再导入真实PostgreSQL、确认原范围报告不变及新快照/附件可读；前端因实际文案变化构建一次。不重跑旧交易或既有工程全套。

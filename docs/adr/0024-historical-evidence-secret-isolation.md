# ADR 0024：历史含密证据的读取隔离（SEC-1）

状态：已采纳；2026-10-12。复用 ADR0006/0020/0022 的只追加证据及公开查询边界。

原本地修复 22245d9 从最新 main 安全整合，不回退 SEC-2。共享敏感文本判定在检测 URL authority 前去掉 TAB/LF/CR，并归一浏览器解释的 authority 反斜杠；只改变检测副本，不修改安全输入。含凭据的元数据拒绝产生快照，CAS 在规范化及哈希前脱敏。

新增采集过滤不能保护旧 Snapshot/任务输入/CAS。公开 JSON 序列化及 Bundle 导出前复用现有 credentials-v1 判定，发现未脱敏内容返回 403 HISTORICAL_EVIDENCE_RESTRICTED。只读关联还检查其源快照和 CAS；不能仅因返回值只有 hash 就继续信任受污染原件。证据服务同样拒绝向调用者返回含密 body。

不在公开接口临时脱敏旧材料：脱敏将使 body 与已承诺 hash 不一致。读取隔离不修改数据库、CAS、链上 Anchor 或历史 ZIP；EvidenceStore.read 的原字节/hash 检查保留，私有离线历史复核能力不变。包含受污染对象的列表整页拒绝，安全历史按原版本返回。无需 Schema、报告格式、DB 迁移、新依赖或逐对象配置。

该门禁只控制本平台 JSON API 和 Bundle 导出。已经分发的静态原件、其他部署和外部缓存必须单独盘点/撤下；真实凭据轮换、吊销及数据删除仍须人工授权。安全的新采集产生自己的版本/hash，保留旧对象 ID/hash 及处置记录，不把旧污染证据升级为安全证据。

验证使用合成凭据，覆盖解析器控制字符、采集 CAS/hash、历史直接/列表/关联读取、证据下载与 Bundle 导出，检查原件字节及 hash 不变；正常 A/D、公共只读和历史离线复核继续运行。实际盘点/测试/独立 Review 与 Git 结果记录于 STATUS。

# ADR-0020：可验证同步查询的可观察服务履约

2026-10-20，实施前固定。评分政策 `service-fulfillment-v1`，PancakeSwap Position Checker `v2`。不修改历史 `service-contract-v1` 的交易履约含义或报告。

## 测量语义与兼容性

A 测量十次相隔30秒的协议发现可用性和延迟；F 测量七个真实业务任务的五项静态事实与独立确认区块是否一致；B 用另外七个真实任务测量**可观察服务履约**：认证登记服务是否对冻结请求交付了关联正确、结构完整、在基准时限内完成的业务结果。B 不比较 token 对、费率、tick 的事实真值，因此错误事实可以 F FAIL、B PASS；错任务或错误交付可 B FAIL。它不证明内部实际计算、隐蔽行为、链上执行、收益、安全性或全部链下行为。

保持 A=10槽且至少8可判、F=7可判、B=7可判，权重30/40/30；同任务键不能进入两个分母。综合分仅适用于该能力及本政策，不和交易履约政策宣称同义或直接排名。未测试为 null。

## B 的证据与判定

每个任务必须有链上认证身份、登记端点、经过安全审阅的接口契约、真实当前Schema、预冻参数/请求ID/对象、独立对象存在性、原始请求计划、计时观测和响应原文。Collector 的 PASS 和 Agent 自报完成字段均不是判据；正式来源 Verifier 从原件重建。

固定基准期限为30秒，单次传输超时配置最多45秒、响应1MiB、零重试。该期限是本次评价窗口，不宣称提供方承诺了SLA；不根据观测结果调整。耗时取客户端fetch的单调时钟观测，覆盖请求传输、代理/DNS/TLS握手、响应读取和本地响应保存，不包含此前客户端构造与证书上下文初始化，也不能独立分离服务端执行时间。因此，超过30秒的完整响应以及连接/读取超时均为UNKNOWN，不能仅凭客户端迟到观测归责Agent；代理/DNS/TLS错误同为UNKNOWN。及时收到完整交付可以证明本次可观察时限要求已满足。

PASS 同时要求：外层JSON-RPC ID精确关联；MCP工具或A2A同步Message的完整业务交付可解析；交付positionId/chain与请求绑定；五项必需字段类型/地址结构完整；端到端观测时间不超过30秒。五项值与链上是否一致留给F，不能复制F结论。

FAIL 仅用于完整可归属协议响应中明确的错误关联、错误业务交付、缺少契约必需结果，以及受审方法和有效冻结输入被明确以JSON-RPC -32601（方法不存在）或-32602（参数无效）拒绝。普通协议内部错误、MCP isError及A2A业务error均为UNKNOWN：错误消息本身不是独立归责证明，不能把任意内部RPC错误或自报失败一律记FAIL。认证/付费/限流为UNKNOWN并按既有规则停止该主机；平台错误为UNKNOWN。对象可能在确认快照后burn导致的not-found不能无证据归责。仅因完整响应超过30秒不能记FAIL；畸形非协议页面、截断响应及缺证据UNKNOWN。完整性篡改、请求或端点被替换拒绝发布，不能降级成UNKNOWN掩盖。

Hallmark当前A2A为同步Message；没有tasks/get或最终artifact链，不把随机响应messageId当回显任务ID。本政策只核交付所需的kind、role、data/skill、subject及五项必需业务字段和外层JSON-RPC ID，不宣称完整验证A2A所有标准字段。两协议使用外层请求关联和业务subject关联的一致语义。未来异步Task需要另行版本化强状态核验，不能凭Task自报completed。

## 自动任务与安全

只使用后台可信BSC RPC及已认证NPM/factory；固定head-64区块及hash。由totalSupply和tokenByIndex按十四个确定性中点分位索引选择活NFT，前七F、后七B；B排除既有v1 F任务。先保存选择规则、全部候选和F/B分配，再参考读取，再冻结完整执行输入，最后才调用业务。枚举证明该快照存在性，F另读取positions；B不依赖F事实正确性。缺失、失效、重复或排除冲突的槽位保留UNKNOWN，不替换、不扩扫、不重试。

上限仍64逻辑公开请求：注册/发现/A最多21，参考6+totalSupply1+枚举14+F positions7，业务14，总63；A2A额外认证Card最多1。预算不因阶段或失败退款，未发送保留原因。若前置采集耗尽预算，剩余槽位UNKNOWN。免费只读、禁止支付/签名/链写入/委托，主机停止规则不变。

执行授权来自本轮用户对两个已审提供方的限定免费只读评价。新提供方必须先认证注册、精确Schema匹配和操作者审阅的零费用/无副作用接口记录；相似名称、LLM判断及readOnlyHint均不构成授权。允许通过审阅配置复用协议映射，不增加Agent专属判分。

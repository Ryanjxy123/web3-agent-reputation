# ADR-0002：候选准入、只读证据采集与可读报告

日期：2026-10-18。状态：已实施候选工具；正式评分仍待后续实现。

## 决定与边界

先实现能验证候选可测性的最小工具，不先搭完整网站后台。六项准入检查为公开注册、具体功能声明、可调用业务接口、独立判据、执行关联、可归属交易历史。仅六项全为 PASS 时派生 `ready_for_full_score`；UNKNOWN、FAIL、NOT_APPLICABLE 或缺项不能成为完整准入。通过准入也不等于已完成采样评分。

共享类型位于 packages/core，保持纯规则，不请求网络、读数据库或取当前时间。Pydantic 类型生成 JSON Schema 和 TypeScript；当前尚无 API，OpenAPI 在实际 API 出现时直接由共享模型生成，不维护虚构接口规格。

外部请求只经 SafeHttpClient，目标由操作者在静态注册表中审阅，不能从 Agent metadata 接受任意 URL 或 RPC。默认不执行；显式开启后才允许已记录的免费只读范围。限制 HTTPS、公网目标、响应大小、超时和请求预算，不跟随重定向、自动重试或自动付款。401/402/403/429 停止该主机，独立主机的已授权工作可继续。

链上核实使用操作者固定的 BNB 官方公共 RPC 配置，先验证 chainId，再记录固定区块和哈希。只允许列出的读取方法及固定注册合约 ABI，不接收元数据中的 RPC，不签名、不发送交易。距 head 64 个区块仅记录观测确认距离，不冒充独立最终性证明。

每轮使用随机目录，先保存范围 manifest，再追加原始响应、HTTP 观测和响应摘要；不覆盖旧证据。采集成功只表示取得响应，不能代替功能或交易正确性。本轮首批旧采集记录中的 functional 表示访问了业务入口，HTTP PASS 仍不是业务判分；它们不进入评分分母，后续可达性检查明确使用 availability。未跨用途复用评分样本。

## 面向用户的报告

当前产物明确命名为“候选可评价性检查”，不是完整声誉报告。先用中文解释结论、已核实内容、缺项及下一步，逐项展示证据；请求、原件路径和哈希折叠。来源和响应均作不可信文本转义，外链仅显示经过检查的 HTTPS 链接。不得生成不存在的分数、失败样本或链上成功结论。

本轮聚合脚本是已审阅候选的可行性工具，包含针对实际材料的六项判断，不是通用的自动接入能力。DeFi 的历史 PASS 只说明存在一条可归属增仓步骤；记录时间与链上事件在本轮调查使用的五分钟窗口内对应。该窗口及成功样本的选取仅用于调查，不是已固定的可靠性评分政策，也不构成任务总体成功率。

正式声誉报告后续仍须逐维解释得分，展示实际输入输出、独立判据、范围、时间、样本和未覆盖内容。离线 HTML 是本阶段的可审阅产物，不改变最终 Vue 网站技术基线，也不计作网站交付完成。

## 兼容性、迁移与验证

无旧数据库或报告迁移。新增准入契约为 candidate-admission-v1，类型及生成文件同批提交。复算使用保留证据，输出新的报告目录，不重复请求、不覆盖旧报告。

必要验证覆盖六项准入、拒绝前端直接指定 READY、公网出口及重定向边界、响应大小、限流停止，以及 HTTP 200 不能判功能通过。实际网络采集单列记录，不将 mock 请求计为公共测评或链上验收。

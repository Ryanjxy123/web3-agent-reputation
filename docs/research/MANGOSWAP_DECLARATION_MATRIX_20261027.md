## 对象与版本

- 注册身份：Ethereum ERC-8004 MangoSwap #26345；既有owner/tokenURI原件与公开Agent Card显式登记关联。
- Agent Mango是套件名称；Spraay #26346的批量支付/x402等归属单列，不自动并入26345。
- 旧实验入口：Spraay网关`POST /api/v1/swap/execute`，实际由买方智能账户调用Base Router02执行ERC20即时兑换。
- 当前MangoSwap自身官网：https://mangoswap.xyz ，公开页面还列出限价、定时及订单管理；这些属于本次必须调查的MangoSwap声明。
- 官网页面使用V4地址`0x1681D47aA3AAEcc47b9CD1d0bA6DF37CD683510e`，与旧API实际Router02路径不同。不能把旧API功能成功自动当作V4或自动订单成功。

## 下一批实验按缺口安排

1. **先只读/模拟**：核V4公开ABI/代码来源、即时/订单方法与角色、路由、收费单位、资产托管与退出规则；找清限价创建入口、自动执行者和周期配置。不能把未认证ABI直接变成转账指令。
2. **补入口与资产模式**：在核实V4调用与费用后，以同一份任务同时取A响应、F条款和B真实结局；补原生ETH路径。已有旧API ERC20正向实验直接复用。
3. **订单生命周期**：分别为限价和一次定时固定一个正常执行案例及独立撤单/退出案例；只要创建，就持续跟踪到约定终态，资金受托管的任务不能留在无人管理状态。不能为验证拒绝向真实第三方发危险调用。
4. **条件与周期声明**：按真实支持钱包验证免gas；按实际调度机制确认周期模式。若没有可用入口/必要条件，保留明确缺口，MangoSwap整体仍不完整，不再凑即时兑换次数。

具体金额、费用、执行时间和停止条件须在每批业务发出前持久化。用户已允许必要付费实验，不因旧0.015USDC单笔限制重复询问；需要新登录、充值、权限变更或真正方向决策时再请求用户操作。禁止发币、身份铸造和不明转出持续适用。

## 可复用边界

即时兑换、限价生命周期、定时/周期生命周期按协议实现判据，MangoSwap只是来源配置。另一个Agent若提供相同能力与可核验任务/接口/合约，则使用同一判定和案例结构。其它Agent没有声明限价功能时无需测限价；声明了却尚未适配时，保留未测，不能发布其全部声明完整评价。

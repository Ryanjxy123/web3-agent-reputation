# 群体能力覆盖与后续投入选择

日期：2026-10-18。评价以功能能力为单位，Agent 与能力多对多。本文用于决定后续投入，不是新评分政策；动作簇不等于评价方案。

## 调查依据

- 九条链、两个登记时间层共取得 554 个不同注册索引。272 个索引有具体业务描述，但只有 106 种不同描述；空资料、角色、默认模板与含糊说明全部保留。109 个代表身份读取详情，其中 72 个有接口声明。采样与质量见 [语料记录](CAPABILITY_CORPUS_20261018.md)。
- 复用既有 14 个对象的 149 条已核来源声明、67 种 operation 文本，未重调 DeepSeek 提取。Codex逐项审阅 81 种原文，区分查询、预测、规划、执行及内部阶段，见 [现有能力映射](INVENTORY_CAPABILITIES_20261018.md)。
- 两组资料合并为 567 个 canonical 注册身份，重叠身份合并。注册数、描述数、功能数和已评分数分别统计。owner、项目名和域名只作提供方线索；本轮没有据此证明独立提供方数量。
- 声明覆盖 D：有来源的当前功能声明，按不同 Agent 去重。可测覆盖 M：同一个 Agent 的接口、许可、独立判据、任务关联和足够历史同时成立。完成覆盖：实际报告完成。不能把不同对象的条件拼成一个可测对象，也不能把 D 当 M。

106 种目录原文经 Codex 语义审阅后，173 个身份有明确的当前动作声明；未展开的交易者角色、过去/未来计划和 6 个明示 inactive 的身份不计当前 D。另有两个对象的 17 段结构化业务说明留待细读，没有把它们偷偷算作已归类能力。详见 [目录语义映射](CAPABILITY_CORPUS_SEMANTICS_20261018.md)。

## 覆盖与价值比较

两组映射按 canonical 合并，**186 个身份有当前直接功能声明**。下表排除了只在工具内部发生的证据搜集等阶段；同一身份可出现在多行，行数不相加。离线汇总与 4 份输入摘要保存在 `runtime/capability-coverage-summary-20261018T082645Z-b3787102/`，实际命令退出 0，没有新网络、外部模型 API 或评分。

| 动作簇（不是评分方案） | 当前声明身份 D | 不同业务原文 | 已证完整三维对象 | 通用建模前仍需解决的主要问题 |
| --- | ---: | ---: | ---: | --- |
| 计算、规划与建议 | 92 | 41 | 0 | 输入与约束不统一；“最优收益”缺可独立复算的目标、协议状态及数据窗口；计划不能当执行 |
| 写入与业务执行 | 40 | 33 | 1 个增仓特例 | 交易、下注、规则修改等不同完成语义；多数缺任务归属/完整历史，主动资产操作不在授权内 |
| 研究、内容、代码与模型操作 | 34 | 25 | 0 | 缺任务级基准和可复核成果，部分为收费模型服务；内部研究阶段不冒充独立接口 |
| 监测与警报 | 33 | 32 | 0 | 需完整时间窗、事件基准及历史警报，单次访问不能验证持续监测 |
| 资料与状态查询 | 30 | 38 | 0 | 需实际参数、固定状态/数据时间与可信来源对照；多数缺任务履约证据 |
| 验证、证明与结果判定 | 16 | 10 | 0 | 身份核对、市场裁决等判据不同；不能复制别人的声誉分充当独立核验 |
| 预测未来状态或事件 | 14 | 33 | 2 个概率预测 | 其中 12 个声明事件概率；另 2 个只声明拥堵/资金费率等未来数值，不套二元概率评分 |

声明数最多的单项是收益机会筛选：**48 个注册身份共用一种原文**。其次有 18 个身份共用下注说明。它们尚未被证明是 48/18 个独立服务或可评分对象，不能用模板数量决定投入。相比之下，现有事件概率能力有 12 个不同 service/Mech，已有两个真实闭环，扩展边界也能具体定位。

其余通信、社区、任务看板等动作 20 个身份保留在映射中。所有未就绪能力都有出处和缺项，不从清单删除；本表的 0 表示尚无已证完整报告，不是已证明没有可测对象。

## 已有预测方案的建模前调查快照

独立资料审查与语义映射均得到 **12 个真正声明二元概率预测的对象**，对应 12 个不同 service 和 Mech。Degen 的预测市场资料查询、已关闭市场裁决、通用模型补全，以及仅带 p_yes 示例的非预测工具不计入该能力。

调查时 **6 个符合当时采集器的注册格式、2 个已完成完整评分**；其余 10 个当时是否各有 14 个合格的不同已结算市场均为 UNKNOWN。这是建模前依据，后续实际批次见下节与STATUS。概率字段在多数 Schema 中只是 result 字符串里的示例，正式结果仍须解析原件并核查数值、问题、时间及结算。详见 [逐对象可测性事实表](EXISTING_CAPABILITY_FEASIBILITY_20261018.md)。

预测专项的共同接入缺口已由ADR-0013实现解决：没有某提供方operator域名时，按官方目录服务号取得唯一Mech线索，再核对桥、service与链上getter；不按对象名添加例外。订阅实现仍未适配；历史充分性仍须实际核实，同factory或同输出格式不等于履约或预测已通过。

## 投入选择

用户已批准先自动挂接已有预测判据、扩大完整评分覆盖，当前任务为 **PREDICTION_AUTO_ATTACH**。注册、来源声明及接口共同决定是否匹配已有 `prediction-history-v1`；仍遵循[按协议自动接入原则](../docs/adr/0009-generic-evaluation-first.md)，不要求每个对象等待专用标准，某项缺资料仍展示其他已有评价。

现已完成注册/协议发现、MCP发现接口可用性、跨工具Mech历史履约及预测判据自动挂接。新对象复用共同的身份发现、资格筛选、14槽冻结与评分路径，不编写对象专属profile。通用F仍未接入，预测效果继续使用独立政策，不转成通用F；原政策及两份既有预测报告不变。当前真实对象数、分数及在途批次见[STATUS](../STATUS.md)。

历史二元概率预测已有真实闭环、独立结算与多对象资料，是本轮已批准的自动挂接方向。按真实业务含义及协议匹配，不锁死对象名单；该专项不是所有新对象产生评价的前提，三维不足仍不生成综合分。

纯只读事实查询是后续通用能力的重要方向：参数与固定状态对照可复用；但市场隐含概率不等于自主预测，查询到交易也不等于本 Agent 执行了交易。具体接口、免费许可、固定状态判据与任务履约证据仍须共同核实，不能为凑综合分把交易行为补成 100。

资产执行可查公开历史，但不新增签名、付款、订阅或真实交易；缺少执行归属和独立状态时保留缺项。计划、检索、代码和监测各有不同完成判据，不能放进一个“万能评测”或按每个项目复制规则。

## 当前任务：PREDICTION_AUTO_ATTACH

本节按用户明确批准推进，沿用独立 [prediction-history-v1](../docs/adr/0008-prediction-history-policy.md)，不是通用F。以下为同协议候选整批资格核实和自动匹配条件，不是所有普通评分的准入条件。批准时为34候选、3个完整对象、10份报告，当前进展以STATUS为准，不因计划获批或报告份数增加而增加完整对象数。

1. 从实际注册、有来源的业务声明及接口自动识别预测候选，整批记录身份、service/Mech、支付实现、明确预测操作、公开历史、独立结算及任务归属。工具名或p_yes示例不作为业务依据，不按对象名特判。
2. 优先核实相同固定价格协议下尚未完成的对象；订阅实现单列，不默认兼容。沿用冻结的 cutoff、不同市场、互斥 7+7 和排除 pilot 规则，不能读完结果后挑分数或降低门槛。
3. 每对象核实14个不同已结算市场及互斥7+7任务资格，按共同协议统一适配，不逐对象新写标准。历史不足或未适配者生成部分报告并保留原因，不降低门槛、不按结果换样本；原政策和2198、2235两份既有预测报告不覆盖。
4. 同时保留一个 Agent 的所有已识别能力及分别适用/缺项状态。平台负责匹配方案；用户不选方案。单份报告仍为单policy；已支持通用逐工具历史履约与新预测报告的逐功能样本关联，通用功能正确性及多专项组合仍未实现，不能宣称已覆盖全部功能。

该轮调查时为3个不同完整Agent、4份报告，通用接入初次达到34候选、10份报告；这两个数字是历史快照。自动批次已继续增加真实完整覆盖，当前结果见STATUS。至少10个完整对象仍为目标，Brain增仓保留特例。扩量缺项与额外目录资料见[有限调查记录](PREDICTION_EXPANSION_DISCOVERY_20261018.md)：缺原件、缺明确市场标识、平台读取故障、截止前空历史与不适用分别保留，不降低门槛或新增单对象标准凑数。
